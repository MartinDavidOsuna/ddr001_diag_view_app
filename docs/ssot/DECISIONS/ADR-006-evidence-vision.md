# ADR-006 — Evidencia obligatoria y lectura asistida
- **Estado:** aceptada
- **Fecha:** 2026-08-08
- **Decisión:** fotos de inicio, intermedias configuradas y final son obligatorias. Si una falla, la corrida es inválida y debe repetirse. Aguja y odómetro se leen automáticamente cuando sea posible; toda lectura automática se confirma por el técnico y puede corregirse antes del cierre.
- **Consecuencias:** una falla de evidencia nunca produce una muestra formalmente válida. OCR/visión son ayudas, no sustituyen la confirmación humana.
