# Android 1.7.4+23 — identificar campos rechazados

HTTP 422 en Envío del expediente significa rechazo de validación del lote.
La versión anterior mostraba sólo el mensaje general e ignoraba la lista de
campos. Esta actualización muestra hasta ocho rutas/códigos en texto
seleccionable bajo SINCRONIZAR. No muestra valores recibidos ni cuerpos crudos.

No modifica API, muestras, payloads, hashes, cámara o adquisición. No afirma
corregida la causa del 422: todavía se requiere el detalle del expediente real.

Validación: 334 pruebas Flutter aprobadas; el fixture MANUAL serializado por
Dart también pasó syncPushSchema de la API sin conectarse a SQL. Ese fixture
no sustituye al JSON del expediente real que fue rechazado.

Instalar sobre 1.7.3 sin desinstalar, abrir el mismo expediente y sincronizar.
Copiar el texto Campos. No repetir ni borrar la verificación.
