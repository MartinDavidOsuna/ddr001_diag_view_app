Fecha: 2026-09-18. Aplicación: com.aquafim.ddr001diagview.

## Cambio

Errores Field problem+json y errores funcionales anidados preservan operación,
HTTP, detalle y referencia de solicitud. Las respuestas HTML o con tipos JSON
inesperados conservan la clasificación de reintento sin mostrar su cuerpo.
Errores del refresh se identifican como renovación, no como la operación
original. No cambia adquisición, metrología, Drift, checksums ni firmware.

Esta versión **no certifica resuelta** la excepción del backend. Permite
identificar el paso fallido desde el Pixel; la recepción requiere ACK real.

## Validación

- Flutter: 331 pruebas aprobadas y analyze sin incidencias.
- API: prueba integral funcional aprobada en DDR001_Hidrantes_TEST, perfil
  construction-test y storage local aislado. Incluye auth, upload, sync, replay
  y controles de ownership/conflicto. No es una prueba de producción.
- Compilación release con app/config/production.json; HTTP al hostname vigente.

## Uso

Actualizar instalando el APK de Download, sin desinstalar la app anterior.
Abrir el expediente existente en Historial y pulsar SINCRONIZAR. Si falla,
compartir el paso, HTTP, detalle y Ref. mostrados. No recrear ni borrar la prueba.
